### B. Storage cleanup (task 3)

The smoke tests check a cancelled job, a failed job and a planted leftover folder in both browsers. By hand, only what they cannot do: a browser that is closed in the middle of a job. Load the build from the pull request and serve the test pages (`pnpm run testpage`).

- [x] Firefox: open `http://127.0.0.1:8123/large.html`, start the download in the popup, kill the browser (Task Manager) at about 30%, start it again, open the popup and wait a minute. The size of the `fs` folder inside `<profile>\storage\default\moz-extension+++<internal uuid>` (`about:support` shows the profile folder, `about:debugging` the uuid) falls from ~1 GB to a few MB. Pass (Dev Edition).
- [x] Chrome: the same, but read the size from the popup tab's console: open `chrome-extension://<id>/popup.html`, F12, run `(await navigator.storage.estimate()).usage / 1048576` (MiB). Chrome sweeps when the browser starts and the service worker wakes, with no stream download needed; the figure may take a little while to fall. The first try, on the PR #40 build, failed (800 MB stayed); the retest on the fix build passed.
- [x] Both browsers: start a stream download after that: it saves as usual. Pass.
