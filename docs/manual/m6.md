### B. Storage cleanup (task 3)

The smoke tests check a cancelled job, a failed job and a planted leftover folder in both browsers. By hand, only what they cannot do: a browser that is closed in the middle of a job. Load the build from the pull request and serve the test pages (`pnpm run testpage`).

- [ ] Open `http://127.0.0.1:8123/large.html`, start the download in the popup, and close the browser (kill it from the Task Manager) while it is at about 30%. Start the browser again, open the popup of any page and leave the browser idle for a minute. Then look at the size of the extension's folder `storage\default\moz-extension+++<id>` in the profile (Firefox, `about:support` shows the profile folder) or `Default\File System` (Chrome): it must be a few MB, not the GB that were written.
- [ ] Start any download after that: it saves as usual, and the folder is small again once it is saved.
