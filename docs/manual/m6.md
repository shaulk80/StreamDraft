### A. Product basics (task 2)

Load the build from the pull request (`pnpm run zip:firefox`, `pnpm run zip:chrome`, or `.output/<browser>-mv3`).

- [ ] Open the popup. The footer shows `Version 0.1.1` (or the version in `package.json`), under the background line.
- [ ] Open Options and scroll down. The About section shows the same version, one sentence on privacy and one on the all-sites access. Both read clearly to someone who has not seen the project.
- [ ] Click "Privacy": the README section Privacy opens in a new tab. Click "Every permission explained": the section Permissions opens. (Both work only after the pull request is merged and the README is on `main`.)
- [ ] Firefox only: `about:addons`, StreamDraft: the Homepage link points to the GitHub project.
- [ ] Read the README sections Privacy and Permissions against what you know of the extension: anything false or missing?
- [ ] Read `docs/store-listing.md`: would you put this text in a store as it stands? Screenshots are not taken yet.
- [ ] Dark theme: the About section and the popup footer are readable.
